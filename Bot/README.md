# TgBot-ollama-v2

**Кратко:** это Telegram-бот, который работает с локальным/самостоятельным сервером Ollama и позволяет каждому держать свои переписки локально — без передачи личной истории в OpenAI/чужие сервисы. Бот поддерживает кастомные *system prompts* (глобальные и приватные), может выдавать разные «личности» (учитель французского, друг, аниме-персонаж и т.д.), работает в личных чатах и в группах (с упоминанием) и поддерживает модели с обработкой изображений (если модель семейства `vl`).

---

# Почему этот проект полезен

* **Приватность:** использует локальный Ollama — ваши сообщения остаются у вас.
* **Гибкость:** легко выбирать/добавлять системные промпты (глобальные и приватные).
* **Персонализация:** можно задать роль бота (например — учитель, персонаж и т.д.).
* **Группы & личные чаты:** работает в личных сообщениях и в группах (бот реагирует на упоминания / ответы).
* **Работа с изображениями:** если модель поддерживает (семейство `vl`) — можно отправлять фото.
* **Простое управление моделями:** загрузка/удаление моделей из Ollama через команды бота.

---

# Возможности (features)

* Регистрация пользователей и хранение в локальной SQLite БД (`users.db`).
* Список команд: `/start`, `/reset`, `/history`, `/pullmodel`, `/addglobalprompt`, `/addprivateprompt`, `/admin`.
* UI-кнопки: About, Register, Switch LLM, Select System Prompt, Select Local System Prompt.
* Переключение между моделями, просмотр доступных моделей с Ollama.
* Добавление/удаление системных промптов через интерфейс.
* Админ-панель: удалить модель, удалить системный промпт, посмотреть/удалить пользователей.
* Стриминг ответа от Ollama — бот отправляет ответ частями и сохраняет историю в БД.
* Поддержка изображений (конвертируется в base64 и отправляется в запрос к Ollama если требуется).

# Быстрый старт — что нужно

* Python 3.10+ (рекомендуется 3.11)
* Установленный и запущенный Ollama (локально или доступный по сети).
* Репозиторий кода (этот проект).
* Зависимости Python:

  * `aiogram`
  * `aiohttp`
  * `python-dotenv`
  * (и любые локальные модули проекта: `InitDB`, `FormatResponse` и т.д.)

Пример установки:

```bash
git clone https://github.com/max-permyakov/TgBot-ollama-v2.git
cd TgBot-ollama-v2
python -m venv .venv
pip install -r requirements.txt
```

# Настройка переменных окружения (.env)

Измените `.env.example` в корне проекта с своими значениями и удалите .example из названия:

```
TOKEN=123456:ABC-DEF...             # Telegram bot token
OLLAMA_BASE_URL=localhost          # адрес где запущен Ollama
OLLAMA_PORT=11434                  # порт Ollama (по умолчанию 11434)
USER_IDS=123456789,987654321       # список id пользователей, разделённых запятыми (для доступа)
ADMIN_IDS=123456789                # id админов
INITMODEL=your-default-model       # например: llama2-13b или другая модель, доступная в Ollama
LOG_LEVEL=INFO
ALLOW_ALL_USERS_IN_GROUPS=0        # 1 — позволить всем участникам групп использовать бота, 0 — только allowed_ids
TIMEOUT=3000                       # таймаут запросов в миллисекундах
```

# MAX Messenger

Этот проект также может работать в мессенджере MAX (long polling).

## Настройки .env для MAX

```
MAX_TOKEN=your_max_bot_token
MAX_API_BASE_URL=https://platform-api.max.ru
MAX_LONGPOLL_TIMEOUT=30
MAX_LONGPOLL_LIMIT=100
MAX_UPDATE_TYPES=message_created,message_callback,bot_started
```

## Запуск MAX-бота

```bash
python bot/run_max.py
```

Примечания:
* В группах бот отвечает только при упоминании `@username` (если `ALLOW_ALL_USERS_IN_GROUPS=0`).
* Поддерживаются inline-кнопки и команды: `/start`, `/reset`, `/history`, `/pullmodel`, `/addglobalprompt`, `/addprivateprompt`, `/admin`.
* В MAX версии обработка изображений пока не реализована (только текст).

# Как пользоваться (коротко)

1. `/start` — стартовое сообщение + кнопки.
2. Нажмите **Register** .
3. Выберите системный промпт через **Select System Prompt** (глобальные) или **Select Local System Prompt** (приватные).
4. Выберите модель через **Switch LLM** или используйте команду `/pullmodel <model_name>` чтобы подтянуть модель с Ollama.
5. Напишите сообщение в чат — бот ответит в приватном чате или в группе при упоминании/ответе боту.

---

# Полезные команды (из кода)

* `/start` — запуск/приветствие.
* `/reset` — сброс активного чата (только для разрешённых пользователей).
* `/history` — вывести историю сообщений (только для разрешённых).
* `/pullmodel <name>` — подтянуть модель из Ollama (логика в `interactions.manage_model("pull", model_name)`).
* `/addglobalprompt <text>` — добавить глобальный системный промпт.
* `/addprivateprompt <text>` — добавить приватный системный промпт.
* `/admin` — открыть админ-панель (только для админов).

Дополнительно: через inline-кнопки можно просматривать/удалять промпты, переключать модели, просматривать список пользователей и удалять их.

# Где хранятся данные

* SQLite база: `users.db` (таблицы — `users`, `system_prompts`, история сообщений и т.д.).
* Логи пишутся в stdout/консоль (уровень LOG_LEVEL в .env).

---

# Настройка Ollama

* Убедитесь, что Ollama запущен и доступен по `OLLAMA_BASE_URL:OLLAMA_PORT`.
* Бот использует конечные точки Ollama:

  * `/api/tags` — список доступных моделей (для переключения).
  * `/api/chat` — чат/генерация (стриминг ответа).
  * `/api/pull` и `/api/delete` (через `/api/<action>`) — для pull/delete моделей.
* Если Ollama расположен на другой машине, настройте firewall и используйте HTTPS/SSH туннель при необходимости.

# Примеры

* Добавить приватный промпт:

  ```
  /addprivateprompt "You are a friendly French teacher. Speak in French and explain grammar concisely."
  /addprivateprompt "You are Batman"
  ```
* Подтянуть модель:

  ```
  /pullmodel llama2-13b
  ```
* Выбрать системный промпт: через кнопку **Select System Prompt** → выбрать нужный текст.

# Отладка / частые проблемы

* `401 Unauthorized` от Telegram — проверьте `TOKEN`.
* Ошибки при подключении к Ollama — проверьте `OLLAMA_BASE_URL`/`OLLAMA_PORT` и что Ollama запущен.
* Пустые ответы или формат JSON ошибки при стриминге — проверьте логи сервера Ollama и логирование в `interactions.py`.
* Если команды не работают в группах — проверьте `ALLOW_ALL_USERS_IN_GROUPS` и `allowed_ids`/`admin_ids`.

---

# Файловая структура (из репозитория)

* `run.py` — основной запуск, обработчики aiogram, UI кнопки.
* `func/interactions.py` — сетевые запросы к Ollama, работа с БД, права доступа.
* `InitDB.py` — модуль инициализации базы (вызывается при старте).
* `FormatResponse.py` — утилиты разбивки сообщений и форматирования (используется при отправке длинных ответов).
